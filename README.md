# RiskyMate

Australian rental property compliance software for agencies, portfolio managers, rental providers, contractors and renters.

RiskyMate coordinates evidence-led compliance work from inspection to completion. Property records, due dates, authority, bookings, field work and proof stay together.

**Website:** [riskymate.com](https://riskymate.com)

Supports Victoria, New South Wales and the Australian Capital Territory.

Built by Adam Petkov-Rothapfel with over 15 years of property management experience.

- **TELL**: Victorian rental planning layer
- **TradieMate**: Trade network for verified tradies (free for tradies)

Private product repository is at RiskyMate/RiskyMate (members only).
